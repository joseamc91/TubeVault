# Seguridad

## Versiones con soporte

TubeVault ofrece soporte de seguridad únicamente para la release publicada más
reciente. Actualmente es `2026.09.006`. Las releases anteriores no reciben
correcciones de seguridad.

## Informar de una vulnerabilidad

No publiques vulnerabilidades sensibles, exploits ni datos personales en un
issue público.

En el [apartado Security del repositorio oficial](https://github.com/joseamc91/TubeVault/security),
comprueba si está disponible la opción **Report a vulnerability** de GitHub
Private Vulnerability Reporting. Si esa opción no aparece, solicita primero un
canal privado mediante los medios de contacto que figuren en el repositorio,
sin incluir detalles técnicos sensibles en público.

Un reporte útil incluye:

- versión de TubeVault y versión de Windows;
- descripción del problema y su impacto potencial;
- pasos mínimos para reproducirlo;
- condiciones necesarias para explotarlo;
- propuesta de corrección, si existe.

Incluye solo los fragmentos de log imprescindibles. Elimina URLs privadas,
rutas personales, nombres de usuario, tokens, cookies, credenciales y cualquier
otro dato que no sea necesario para investigar el problema.

Los reportes se revisarán antes de divulgar detalles públicamente. No se promete
un plazo concreto de respuesta hasta que exista un proceso público de
mantenimiento formalizado.
