# TubeVault 2026.09.007 — Public preview

Esta es la primera publicación pública de TubeVault en GitHub. Se ofrece como
**pre-release / public preview** para probar la distribución prevista antes de
incorporar firma digital.

El asset principal es `TubeVault-2026.09.007-win-x64.msi`, un instalador x64 para
Windows. La instalación es per-user en `%LocalAppData%\Programs\TubeVault` y, en
condiciones normales, no requiere permisos de administrador. La aplicación es
self-contained e incluye el runtime de .NET necesario.

yt-dlp, FFmpeg y ffprobe no se incluyen en el MSI. TubeVault los descarga desde
las fuentes configuradas durante el primer arranque, verifica su integridad y
valida los ejecutables antes de instalarlos. En modo instalado, la configuración,
los logs y las herramientas se guardan en `%LocalAppData%\TubeVault`.

## Important: unsigned preview

Esta build todavía **no está firmada digitalmente**. SignPath Foundation todavía
no ha aprobado TubeVault y el proyecto no dispone actualmente de certificado de
firma.

Windows Smart App Control puede bloquear la aplicación. En una prueba real,
Smart App Control bloqueó `TubeVault.dll` por no disponer de firma digital. No se
recomienda desactivar Smart App Control para ejecutar esta preview.

Esta publicación pública también permitirá completar los requisitos previos de
una futura solicitud de firma. Su existencia no garantiza que SignPath Foundation
vaya a aprobar el proyecto.

## Funcionalidad destacada

- Análisis de enlaces de YouTube y YouTube Music.
- Descarga MP3 de canciones individuales y playlists.
- Selección parcial de elementos de una playlist, conservando sus índices.
- Calidad MP3 Alta, Media o Baja.
- Interfaz en español e inglés, con temas claro y oscuro.
- Preparación automática de yt-dlp, FFmpeg y ffprobe en el primer arranque.
- Verificación mediante checksums oficiales y validación de versiones.
- Progreso visible, cancelación segura y detección de archivos existentes.
- Configuración y logs almacenados localmente.
- Soporte técnico para modo portable mediante `portable.flag`; no se publica
  todavía un asset portable en esta preview.

## Limitaciones conocidas

- La build y el instalador no están firmados; Smart App Control puede bloquearlos.
- El instalador utiliza la interfaz mínima de Windows Installer.
- TubeVault no dispone de actualización automática propia.
- Todavía no se publica un ZIP portable.
- No se incluyen cookies ni autenticación.
- Las carátulas no se incrustan en los archivos MP3.
