# TubeVault 2026.09.008 — Public preview

Esta versión fue publicada como **Public Preview / Pre-release**, centrada en
**TubeVault Portable** como único formato de distribución. Su asset es
`TubeVault-2026.09.008-win-x64-portable.zip` para Windows x64.
Extrae todo el ZIP y ejecuta `TubeVault.exe`; no requiere instalar .NET.

La aplicación y el runtime se agrupan en `TubeVault.exe` mediante .NET Single
File. .NET puede utilizar sus propios mecanismos internos de extracción.

## Distribución Portable única

- ZIP inicial de cuatro archivos en raíz: `TubeVault.exe`, `LICENSE`,
  `PRIVACY.md` y `THIRD-PARTY-NOTICES.md`.
- TubeVault es portable por definición: se elimina la detección mediante
  `portable.flag` y el almacenamiento del antiguo modo instalado.
- Los datos se crean bajo `data/config`, `data/logs` y `data/tools`.
  `data/` no se incluye en el ZIP inicial; el destino MP3 lo elige el usuario.
- yt-dlp, FFmpeg y ffprobe no se distribuyen en el ZIP: se obtienen y validan
  durante la preparación inicial.
- La preparación conserva componente, progreso, porcentaje y MB, y muestra
  «Esto solo será necesario la primera vez.» cuando corresponde.
- Se elimina la infraestructura activa MSI/WiX y Portable Classic. El enfoque
  de instalación explorado en `2026.09.007` permanece en el historial.
- Build y CI se simplifican a un único ZIP y artifact Portable.

Para mover TubeVault conservando configuración, herramientas y logs, mueve la
carpeta completa, incluido `data/`.

## Important: unsigned preview

TubeVault todavía **no está firmado digitalmente** y no existe integración
activa de firma. SignPath Foundation rechazó la solicitud el 30/09/2026 por
visibilidad/confianza pública todavía insuficiente. Podrá volver a solicitarse
si el proyecto obtiene más señales públicas de adopción y actividad.

TubeVault Portable se probó de principio a fin en un equipo Windows 11 con
Smart App Control activo: arrancó sin bloqueo, preparó las herramientas, analizó
YouTube Music, descargó MP3 y lo validó mediante ffprobe. El resultado fue
**1 descargado y 0 fallidos**.

Esta prueba acredita únicamente el equipo probado; no garantiza el mismo
resultado en todos los equipos. No se recomienda desactivar Smart App Control
ni SmartScreen, añadir exclusiones o desbloquear archivos para ejecutar esta
preview.
